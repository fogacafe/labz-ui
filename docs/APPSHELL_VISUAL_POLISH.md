# AppShell visual polish

This pass focuses on low-chrome, dense desktop navigation:

- Subtle separator between sidebar and workspace
- Increased sidebar group hierarchy and page indentation
- Accessible page names include module and page
- Subtle hover and pressed states for navigation buttons
- Compact workspace tab strip (40px) with 32px tabs
- Tab labels with consistent padding and hover affordances

This is a visual-only iteration. Navigation, tenant lifecycle and
keyboard shortcut behavior remain unchanged.

## Manual Windows review

Check light/dark themes, 100%/150%/200% scaling, keyboard focus,
narrow windows, text truncation, and tab close buttons in the Showcase.
