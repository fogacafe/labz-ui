# Contributing

Thanks for helping make Windows Forms better!

1. Open an issue to discuss substantial new components or breaking API changes.
2. Fork the repository and create a focused feature branch.
3. Add tests for behavior, theme states, keyboard interactions, and validation when applicable.
4. Run `dotnet test Labz.UI.slnx` on Windows.
5. Submit a pull request with screenshots for visual changes.

Keep public APIs designer-friendly: public parameterless constructors, browsable properties and standard WinForms events.
